# Rechts vor Links

A browser game for practising German right-of-way rules (StVO) by driving through junctions.

**Play:** open `index.html` in a browser, or use the GitHub Pages link of this repository.

- 114 course rounds across 12 junction types: no signs (rechts vor links), priority roads with yield/stop signs and shark teeth, bent priority roads, traffic lights with green arrows, a police officer, and a driveway exit
- Your car starts on every road and does every manoeuvre; the other cars drive themselves by the same rules
- Map, PPP (third person) and FPP (first person) views
- German examiner voice and subtitles („Nach rechts.“, „Richtig.“)
- Works with keyboard (W/A/S/D, Q/E indicators) and on phones (touch controls, steering assist)

Single self-contained HTML file; the 3D views load three.js from cdnjs.
